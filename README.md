## 🚀 Quick Start

### Local Testing (Before Publishing)
1. Download all files to a folder named `pranavi-19th-birthday`
2. Add your 3 photos to an `images/` subfolder
3. Open `index.html` in your web browser to see it locally

### Publishing to GitHub Pages

**Prerequisites:**
- GitHub account
- Git installed on your computer (or GitHub Desktop)

**Steps:**

1. **Create a GitHub Repository:**
   - Go to [github.com](https://github.com)
   - Click "+" → "New repository"
   - Name: `pranavi-19th-birthday`
   - Select "Public"
   - Click "Create repository"

2. **Push Your Files:**
   ```bash
   cd pranavi-19th-birthday
   git init
   git add .
   git commit -m "🎉 Create Pranavi's 19th birthday website with love"
   git branch -M main
   git push -u origin https://github.com/YOUR-USERNAME/pranavi-19th-birthday.git
   ```
   *(Replace YOUR-USERNAME with your actual GitHub username)*

3. **Enable GitHub Pages:**
   - Go to your repository on GitHub
   - Click Settings → Pages
   - Under "Build and deployment" → Source: Select "Deploy from a branch"
   - Branch: Select `main` / root folder
   - Save
   - Wait 2-3 minutes

4. **Your website is LIVE! 🎉**
   ```
   https://YOUR-USERNAME.github.io/pranavi-19th-birthday
   ```

## 🎨 Customization

### Change Colors
Edit the color variables in `index.html` (in the `<style>` section):
```css
--lavender: #e8d5f2;
--mint: #c8e6e1;
--peach: #ffd4b4;
--pink: #ffc7d9;
```

### Update Text
Simply open `index.html` in any text editor and modify the text content. No coding knowledge needed!

### Add More Photos
Copy-paste the polaroid section and add `photo4.jpg`:
```html
<div class="polaroid">
    <img src="images/photo4.jpg" alt="Memory 4" class="polaroid-image">
    <div class="polaroid-label">Your Label</div>
</div>
```

## 🔧 Troubleshooting

**Photos not showing?**
- Ensure your images are named exactly: `photo1.jpg`, `photo2.jpg`, `photo3.jpg`
- Check that they're in the `images/` folder
- Verify file extensions (.jpg, not .jpeg)

**Website looks different locally vs. GitHub?**
- Wait 3-5 minutes after pushing for GitHub Pages to rebuild
- Hard refresh your browser (Ctrl+Shift+R or Cmd+Shift+R)

**Need to update content?**
1. Edit `index.html` in a text editor
2. Save the file
3. Commit and push to GitHub:
   ```bash
   git add index.html
   git commit -m "Update birthday message"
   git push
   ```
